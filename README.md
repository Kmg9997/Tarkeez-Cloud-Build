# تركيز — Android MVP

مشروع Android أصلي بـ Kotlin وJetpack Compose، باللغة العربية ويعمل دون اتصال بالإنترنت. يتضمن جلسة من 8 ألغاز أو جلسة قصيرة من 3 ألغاز، درجات ومستويات محفوظة محلياً باستخدام SharedPreferences، وخطة أسبوعية من السبت إلى الخميس.

## التشغيل
1. افتح مجلد Tarkeez في Android Studio.
2. استخدم JDK 17، ثم نفّذ Gradle Sync (يتطلب الإنترنت لأول تنزيل للاعتمادات).
3. شغّل التطبيق على جهاز Android 8 أو أحدث.
4. لبناء APK اختر Build > Build APK(s).

## حدود النسخة الحالية
- هذه نسخة أولية قابلة للتطوير، وليست تطبيقاً مكتملاً.
- الألغاز الحالية أربعة أنماط مبسطة؛ لا تتضمن بعد ذاكرة بصرية حقيقية بإخفاء العناصر، ولا اختباراً معيارياً للمهارات.
- الصعوبة تتغير بصورة أولية، ولا يوجد بعد محرك تكيفي متقدم.
- لا توجد إشعارات أو إحصاءات يومية أو قاعدة Room بعد.
- لم يُبنَ APK ولم يُختبر على جهاز في هذه البيئة.
